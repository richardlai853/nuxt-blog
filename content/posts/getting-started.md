# Getting Started

Create new markdown files in `content/posts` with frontmatter fields:

- `title`
- `description`
- `date` (YYYY-MM-DD)
- `tags` (string array)
- `draft` (boolean)

Draft posts are excluded from listings when `draft: true`.
