# SEO Checklist

Before launching, verify:

1. Meaningful title and description on every post
2. Canonical URLs configured
3. `robots.txt` and `sitemap.xml` endpoints available
4. RSS feed is valid and discoverable

This starter includes defaults you can extend per environment.
